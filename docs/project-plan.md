# BERT 아이러니 탐지 미니 프로젝트

## 목적과 설계
과제의 여섯 항목을 한국어 설명과 실행 가능한 Colab 노트북으로 제공한다.
영어 BERT `google-bert/bert-base-uncased`와 TweetEval `irony`의 공식 분할을 사용한다.
학습 데이터로만 TF-IDF 기준 모델과 BERT를 학습하고, 검증 macro F1으로
BERT 체크포인트를 선택한다. 테스트 데이터는 최종 평가에만 사용한다.
Accuracy, macro F1, irony F1, precision, recall, 혼동행렬과 오분류를 저장한다.
노트북에서 입력한 영어 문장을 저장된 모델로 추론한다.

테스트 예측 재현, 빈 입력 거부, 잘림 표시, 성능표 재계산과 ZIP 검증을 통과했다.
실제 결과와 실패 사례는 `REPORT.md`에 기록했다.

## 검증 범위
학습 성능은 실행으로 생성된 값만 보고한다. GPU/라이브러리/네트워크가
제공되지 않아 전체 학습을 수행할 수 없으면 그 사실을 명시한다.
빈 입력을 거부하고, 긴 입력의 잘림을 표시하며, 영어 전용임을 안내한다.
아이러니 여부는 감정의 긍정·부정이나 작성자의 실제 의도를 확정하지 않는다.
